# Doc Scan MVP — Client

Vite + React app with two roles (desktop viewer and phone uploader). See the
[top-level MVP README](../README.md) for how this fits together and how to run it
alongside `mvp/server`.

## Scripts

- `npm run dev` — start the Vite dev server.
- `npm run build` — type-check and build for production.
- `npm run lint` — run Oxlint.

## Configuration

- `VITE_SERVER_URL` — base URL of the relay server (defaults to `http://localhost:4000`).
